# PreLens3
AI-Enabled Learning Platform for MoSPI

PreLens3 is a competency assessment, skill-gap analysis, learning roadmap, and MCQ generation platform for MoSPI training workflows.

## Run Locally

Prerequisites: Node.js

1. Install dependencies: `npm install`
2. Add `GEMINI_API_KEY` to `.env.local` for Gemini-powered generation and mentoring.
3. Start the app: `npm run dev`

## Build

`npm run build`

The project includes `vercel.json` for Vercel deployment and serves the Express API through `/api`.
